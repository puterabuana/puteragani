# Putera Gani

[Putera Gani](https://puteragani.com/) is an independent editorial publication exploring technology, design, culture, science, business, and health.

The site publishes researched, long-form articles about the ideas, systems, and creative decisions shaping modern life. It is designed and maintained by Putera Buana Gani.
